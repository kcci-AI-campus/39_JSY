## 🎮 Projects

### ✊✌️🖐️ Raspberry Pi AI 가위바위보 게임

**Raspberry Pi와 카메라를 이용한 2인용 AI 가위바위보 게임**

AI 시스템 반도체 설계 교육 과정에서 학습한 **CNN과 On-device AI 기술을 실제 프로젝트에 적용**하여 제작했습니다.

카메라로 실시간 영상을 입력받고, AI 모델을 이용해 손의 모양을 **가위 / 바위 / 보**로 분류한 후 두 플레이어의 승패를 판단합니다.

#### ✨ Features

* 📷 카메라를 이용한 실시간 영상 입력
* ✋ 최대 2명의 손 인식
* ✊ 가위 / 바위 / 보 분류
* ⏱️ 3초 카운트다운
* 🎯 여러 프레임의 결과를 수집하여 최종 결과 결정
* 🏆 2인 승패 및 점수 표시
* 🔄 게임 상태에 따른 자동 진행 및 초기화
* 📱 Raspberry Pi에서 AI 모델 직접 추론

#### 🛠️ Tech Stack

`Python` `CNN` `TensorFlow Lite` `OpenCV` `MediaPipe` `Raspberry Pi 5`

#### 🔄 System Flow

```text
📷 Camera
   ↓
Image Input
   ↓
Preprocessing
   ↓
CNN Model
   ↓
AI Inference
   ↓
✊ Rock / ✌️ Scissors / 🖐️ Paper
   ↓
Player Result
   ↓
🏆 Winner & Score
```
